# Agent Runs

Agent Run receipts record what happened when an agent implemented against a Product Spec.

Use this folder for `.agent-run.json` files when a run is substantial enough to need a durable receipt. Generated `.agent-handoff.md` files can also live here as implementation inputs derived from Product Specs.

See [ProductSpec directive](../living/project/processes/productspec-directive.md).
