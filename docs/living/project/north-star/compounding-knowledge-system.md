# Compounding Knowledge System

The AI Intuition Compiler is not a content collector.

It exists to turn high-signal external thinking into durable personal judgment about AI systems, product architecture, strategy, and market structure.

## Working-Backwards Goal

Build a compounding system that answers:

> What should I now believe differently, and why?

The weekly brief, raw transcripts, source registry, and extraction packets are implementation artifacts. The durable product is the belief graph.

## Knowledge Layers

1. Evidence layer: raw articles, transcripts, timestamps, quotes, URLs, source metadata.
2. Insight layer: mechanisms, design laws, failure modes, eval patterns, market-structure claims, and boundary conditions.
3. Perspective layer: source fingerprints, recurring priors, disagreements, and blind spots.
4. Belief layer: synthesized worldview updates with confidence, evidence, and open questions.

## Source Admission Rule

Do not add sources only because they are interesting.

A source should earn its place by occupying a useful perspective slot, such as:

- frontier primitives
- reliability failures
- product adoption patterns
- strategy and value capture
- frontier priors

The system should optimize for surprise, durability, and mental-model impact rather than coverage.

## Durable Skill

The durable skill this repo should train is:

> Turning other people's arguments into explicit, testable judgment.

The pipeline should preserve evidence, extract mechanisms, compare perspectives, and update beliefs. It should reject content that only produces summaries.
