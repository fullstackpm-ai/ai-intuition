# Living Documentation

Living docs describe the AI Intuition Compiler as it works today.

This repo is small, so living documentation is organized by project concern instead of team ownership.

## Project Docs

- [Project documentation index](project/index.md)

## Categories

- `knowledge-transfer`: domain context and explanations that are not obvious from code.
- `runbooks`: commands and procedures for operating the pipeline.
- `north-star`: target architecture and enduring product direction.
- `processes`: shared workflows and maintenance rules.

Living docs should change in the same PR or patch as the behavior they describe.
